# Rewari Real Estate Investment Intelligence

### Python | Machine Learning | Data Analytics | Power BI

## Project Overview

An end-to-end real estate investment analysis and decision-support project focused on Rewari, Haryana, India.

The project analyzes historical collector rates from 2023–2026 and explores long-term property investment opportunities through forecasting, comparative analysis, and interactive dashboards.

The predictive analysis focuses on two property categories:
- Residential
- Commercial

## Project Objectives

- Analyze historical property rate trends across Rewari.
- Compare residential and commercial property segments.
- Identify potential investment opportunities at area and segment level.
- Generate indicative forecasts for 2027–2041.
- Evaluate projected appreciation, CAGR, and investment risk.
- Present insights through interactive Power BI dashboards.

## Project Workflow

1. Historical data collection (2023–2026)
2. Data auditing and cleaning
3. Rural and urban classification
4. Area and segment standardization
5. Historical trend and CAGR analysis
6. Long-term forecasting (2027–2041)
7. Investment opportunity and risk analysis
8. Power BI dashboard development

## Project Structure

The repository is being organized into Python scripts, datasets, forecasting outputs, dashboards, and documentation.

## Scope and Limitations

The predictive model focuses on residential and commercial properties.

Agricultural land is excluded from the current predictive scope because the historical dataset does not retain the complete highway-proximity classification needed to distinguish multiple land-rate segments within the same village.

The long-term forecasts are analytical estimates based on limited historical observations, not guaranteed future market prices or financial advice.
